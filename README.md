# 📈 Stock Portfolio Tracker (Python)

## 📌 Project Overview
The Stock Portfolio Tracker is a simple Python-based console application that helps users calculate the total value of their stock investments.  
Users can enter stock names and quantities, and the program computes individual and total investment values using predefined stock prices.

This project was developed as part of the **CodeAlpha Python Programming Internship**.

---

## 🎯 Features
- Predefined stock price list using Python dictionaries
- User input for stock names and quantities
- Calculates individual stock value and total portfolio value
- Displays a clear portfolio summary
- Saves investment details to a text file (`portfolio.txt`)
- Beginner-friendly and easy to understand

---

## 🛠️ Technologies Used
- **Language:** Python
- **Concepts:**  
  - Dictionaries  
  - Loops  
  - Conditional statements  
  - File handling  
  - Console input/output  

---

## ▶️ How to Run the Project
1. Install Python (version 3.x recommended)
2. Download or clone this repository
3. Open a terminal or command prompt
4. Navigate to the project folder
5. Run the program using:

```bash
python stock_tracker.py
```

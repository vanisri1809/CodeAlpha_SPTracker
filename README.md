# 📈 Stock Portfolio Tracker (Python)

## 📌 Project Overview
The Stock Portfolio Tracker is a simple Python console application that helps users calculate the total value of their stock investments.
Users enter stock names and quantities, and the program calculates individual and total investment values using predefined stock prices.

This project was developed as part of the **CodeAlpha Python Programming Internship**.

---

## 🎯 Features
- Uses predefined stock prices with Python dictionaries
- Accepts user input for stock names and quantities
- Calculates individual stock value and total portfolio value
- Displays a clear portfolio summary
- Saves output to a text file (`portfolio.txt`)

---

## 🛠️ Technologies Used
- Python
- Dictionaries
- Loops
- Conditional statements
- File handling
- Console input/output

---

## ▶️ How to Run
1. Install Python (version 3.x)

3. Open terminal / command prompt
